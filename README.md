# Secrets Project

A simple web application built using **Node.js, Express.js, EJS, and Axios** that fetches random secrets from an external API and displays them dynamically on a webpage.

## Features

- Built with Express.js backend
- Uses EJS as the template engine
- Fetches data from an external Secrets API using Axios
- Displays a random secret with the username of the person who submitted it
- Uses static files for styling

##  Tech Stack

- Node.js
- Express.js
- EJS
- Axios
- HTML/CSS
- JavaScript
